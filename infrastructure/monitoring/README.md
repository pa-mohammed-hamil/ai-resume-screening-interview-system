# Grafana Monitoring

Grafana dashboards for the AI Resume Screening & Interview System.

## Dashboards

- Backend API
- PostgreSQL Database
- Celery Workers
- AI Processing
- Interview Engine

## Prometheus

Prometheus is configured as the default Grafana data source.

Docker URL:
http://prometheus:9090

## Grafana

Default local URL:
http://localhost:3000

Configure credentials through environment variables.
